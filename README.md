## 1. 它能做什么

Code Typer 是一个 VSCode 扩展。先导入一份代码文件，打开开关后，你在编辑器里**随便敲任何键**，屏幕上出现的都不是你敲的字符，而是导入文件的内容——按字符一个接一个地输出，效果和亲手逐字敲入完全一致。

典型用途：录屏、演示、直播时，让任意敲击键盘都产出正确代码。

- 你敲 `z`，屏幕出现导入代码的下一个字符；
- 空格、回车、符号键同样只起"催动下一个字符"的作用；
- 输出位置固定，中途用鼠标点到别处也不会打乱顺序；
- 全部字符输出完后自动关闭，之后按键恢复为正常输入。

扩展外观与普通 VSCode 功能无异：命令面板中显示为 `Code Typer` 开头的命令，右下角有一个普通状态栏项。

暂时仅支持vscod 
在确保电脑中有vscod后先点击 安装文件
使用前看我和操作手册可以解决大部分问题

## 2. 安装

1. 获取安装包 `code-typer-0.5.0.vsix`；
2. 在 VSCode 中按 `Ctrl+Shift+P`（macOS 为 `Cmd+Shift+P`）打开命令面板；
3. 输入并执行 `Extensions: Install from VSIX...`；
4. 选择该 `.vsix` 文件，安装完成后即可使用（无需重启）。

升级时重复上述步骤并选择覆盖安装，然后执行
`Developer: Reload Window` 即可。
